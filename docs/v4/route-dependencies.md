# Shared route helpers

`control/route_deps.py` holds what every route group needs, as plain functions of the application context:
`node_auth`, `console_user`, `optional_console_user`, `audit`, `audit_in`, `run_row` and `fenced`, plus the
`github_connection_used` context variable and the `h` token hash. They used to be closures inside `create_app`, which kept every
route inside `api.py`.

- `api.py` keeps one-line delegations with the same names, so existing handlers are unchanged.
- A router in `routes/` uses `Depends(route_deps.node_auth_dependency)` and `route_deps.console_user_for(request, ...)`; both read
  the context from `request.app.state.ctx`, never from a closure and never from `api.py`.
- Messages, status codes, audit rows and the licensing check are identical to the closures they replaced
  (`tests/v4/test_route_deps.py`).
