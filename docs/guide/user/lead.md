# User guide: Lead

**Assumes:** you are signed in to Command Center with the `lead` role and AI Flow v4 is installed with at least one
project. A Lead reads: you can see the console, node operation history and Knowledge, but you cannot change
integrations, nodes, projects or policies. Ask an [Owner](owner.md) for those changes.

## What you can do

| Task | Screen |
|---|---|
| Check requirement coverage and progress of an epic, and export a report | [Team Lead](../screens/lead.md) |
| See the board, tickets that need attention and recent runs | [Delivery](../screens/delivery.md) |
| Follow incidents and fleet health | [Command Center](../screens/cc.md) and [SA health](../screens/sa.md) |
| Read study cases, skills and guides | [Knowledge](../screens/knowledge.md) |
| See epic progress and change requests | [Business](../screens/business.md) |

## A usual week

1. Open [Team Lead](../screens/lead.md), pick the project and check that every epic has enough tasks for its acceptance criteria.
2. Open [Delivery](../screens/delivery.md) and read "Needs attention": tickets waiting on a person, older than 30 minutes, or whose last run did not finish.
3. Export the progress report (Markdown, CSV or printable HTML) for your stakeholders.

If a control is missing from a screen, your role does not allow it; this is not an error.
