# AI Flow documentation

**Assumes:** you use AI Flow v4 (the Command Center console) and, for the administrator pages, that the control
plane is installed. Each page starts with a line like this one that says who it is for and what it assumes.

This site ships inside every AI Flow release. The copy you are reading matches the release you run; the version
is shown at the bottom of each page and in the console footer.

## Where to start

| You are | Start here |
|---|---|
| A Super Administrator | [User guide: Super Administrator](user/super_admin.md) and the [administrator guide](admin/install.md) |
| An Owner | [User guide: Owner](user/owner.md) |
| A Lead | [User guide: Lead](user/lead.md) |
| An operator with an alert | [Runbooks](runbooks/index.md) |
| A developer integrating | [API reference](reference/api.md) |

## What is here

- User guides, one per console role.
- One page for every console screen. The **Help** link in the console top bar opens the page of the screen you are on.
- The administrator guide: [install](admin/install.md), [upgrade](admin/upgrade.md), [backup](admin/backup.md) and [security](admin/security.md).
- [Runbooks](runbooks/index.md): one page for every kind of incident AI Flow raises.
- The [API reference](reference/api.md), generated from the code at build time.

Longer feature descriptions for developers are in `docs/v4/` of the repository.
